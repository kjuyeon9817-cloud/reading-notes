# 독서노트

하루에 여러 권을 나란히 읽으며, 직접 쓰는 독서 기록장이에요. 컴퓨터와 휴대폰에서 같은 기록을 이어 쓸 수 있어요.

## 기록하는 순서

1. **책 목록**: 읽기 시작한 날, 며칠째 읽는 중인지, 책 이름, 저자, 종이책/전자책
2. **이 책을 읽게 된 이유**
3. **발췌한 문장**과 그 문장을 고른 이유
4. **오늘 읽은 곳까지 내용 정리**
5. **현실에 적용하기** 1~3가지
6. **다음 날 실천 체크**: 실천했다면 무엇이 달라졌는지, 못 했다면 왜인지

## 쓰는 법

- 이 저장소의 GitHub Pages 주소로 접속해요. 휴대폰에서는 "홈 화면에 추가"를 해두면 앱처럼 열려요.
- 기록은 먼저 그 기기에 저장돼요.
- **설정**에서 GitHub 아이디, 기록 저장소 이름(`reading-notes-data`), 토큰을 넣으면 비공개 저장소의 `books/` 폴더로 동기화돼요. 토큰은 페이지가 열려 있는 동안 사용해요. 새로 열면 다시 입력해요.
  - 토큰: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  - Repository access: `reading-notes-data` 하나만
  - Permissions: Contents → Read and write
- 설정 화면의 **백업 내려받기**로 현재 저장소의 기록과 해결 전 동기화 충돌을 파일 하나로 받아둘 수 있어요. 불러오기는 현재 목록에 없는 책을 추가해요.
- 두 기기에서 다른 날짜나 항목을 수정하면 변경을 합쳐요. 같은 항목이 겹치면 설정의 **동기화 충돌**에서 양쪽 기록을 확인하고 선택할 수 있어요.
- 지운 책은 설정의 **휴지통**에서 복원할 수 있어요. 저장소를 변경하면 그 저장소에 연결된 기록이 열려요.

## 포스팅용 글 만들기

책 화면에서 **이 날 기록으로 포스팅용 글 만들기**를 누르면 같은 기록이 네 가지로 바뀌어요. 내가 쓴 문장은 그대로 두고 순서와 형식만 바꿔요.

- **네이버 블로그**: 제목 + 본문(책 정보, 어제 실천 결과, 오늘의 문장과 고른 이유, 정리, 적용, 해시태그)
- **Threads**: 500자 안쪽으로 나눈 이어지는 글
- **롱폼 대본**: 장면마다 화면에 띄울 글과 내 목소리로 읽을 말, 예상 길이
- **쇼츠·릴스 대본**: 문장 하나 + 고른 이유 + 적용 하나, 60초 안쪽

목록 화면의 **오늘 기록으로 롱폼 대본 만들기**는 같은 날 읽은 책을 모두 묶어 3~5분 영상 대본을 만들어요. 설정의 **내 인사말**에 적은 말은 시작과 끝에 그대로 들어가요.

## 타깃 맞춤 재구성 (선택)

포스팅용 글 화면의 **✨ 타깃 맞춤 재구성** 탭에서, 내 기록을 재료로 고른 어투(바이럴 후킹 / 친근·유쾌 / 전문가 / 직설)와 **목표 독자**에 맞춘 Threads·X 글을 AI가 다시 구성해요.

- 기록에 없는 경험, 사례, 숫자는 지어내지 않게 하고, 책에서 옮긴 문장은 그대로 쓰게 해요.
- 결과는 바로 고칠 수 있고, 고친 내용은 그날 기록에 저장돼요.
- 쓰는 AI는 아래 맞춤법 다듬기와 같은 설정(LM Studio / Ollama / Claude)을 따라요.

## 맞춤법·문맥 다듬기 (선택)

포스팅용 글 화면 위쪽의 **살펴보기**를 누르면 AI가 오타, 띄어쓰기, 뜻이 안 통하는 곳을 찾아 **제안만** 해요. 바뀌는 곳이 표시되고, **적용**을 누른 것만 기록에 반영돼요. 말투는 바꾸지 않고, 책에서 옮긴 문장은 보내지도 않아요. 설정에서 AI를 골라요.

### 내 컴퓨터 (LM Studio)

1. LM Studio → Developer 탭 → 서버 켜기 (Status: Running, 주소 `http://127.0.0.1:1234`)
2. Server Settings → **Enable CORS** 켜기
3. 앱 설정 → **LM Studio** → **모델 목록 불러오기** → 모델 고르기 (예: `google/gemma-4-e2b`)

### 내 컴퓨터 (Ollama)

기록이 컴퓨터 밖으로 나가지 않고 요금이 없어요. Ollama가 켜진 그 컴퓨터의 브라우저에서만 돼요.

1. Ollama에 모델 받기 (예: `ollama pull gemma3n:e4b`)
2. 이 웹 주소에서 Ollama를 부를 수 있게 허용하기. Windows 기준:
   - 시작 → "환경 변수" 검색 → **계정의 환경 변수 편집**
   - 새로 만들기: 이름 `OLLAMA_ORIGINS`, 값 `https://kjuyeon9817-cloud.github.io`
   - 작업 표시줄의 Ollama 아이콘 → **Quit Ollama** 후 다시 실행
3. 앱 설정 → **내 컴퓨터 (Ollama)** → **모델 목록 불러오기** → 모델 고르기

### Claude

설정 → **Claude**에 API 키를 넣어요 (platform.claude.com에서 발급, 쓴 만큼 요금). 키는 GitHub 토큰처럼 화면이 열려 있는 동안만 기억하고 저장하지 않아요.

## 스레드·X 글 생성기 (standalone.html)

LM Studio 로컬 AI로 Threads·X 글을 만드는 별도 페이지예요. `standalone.html` 파일 하나를 브라우저로 열거나, GitHub Pages 주소 뒤에 `/standalone.html`을 붙여 열어요.

- LM Studio → Developer 탭 → Start Server, 서버 설정에서 **Enable CORS** 켜기
- 🧠 딥리서치(리서치 → 전략 설계 → 최종 작성, 3번 호출) / ⚡ 빠른 생성(1번 호출)
- 추론 모델의 생각 과정은 본문에 넣지 않고 "생각하는 중" 표시로만 보여줘요.
- 생성 기록 20개는 페이지를 닫으면 사라져요.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 틀 |
| `style.css` | 디자인 (밝은/어두운 모드) |
| `app.js` | 기록, 저장, GitHub 동기화, 화면 |
| `proofread.js` | 맞춤법·문맥 다듬기 요청 (공식 Anthropic SDK 사용) |
| `vendor/anthropic-sdk.js` | 브라우저용으로 묶은 Anthropic SDK |
| `standalone.html` | LM Studio 딥리서치 스레드·X 글 생성기 (독립 실행) |
| `formats.js` | 기록 → 블로그·Threads·대본 변환 (브라우저와 Node 둘 다에서 사용) |

기록 파일 형식(`books/<책id>.json`)은 이후 블로그·Threads·영상 대본 변환 단계에서 그대로 읽어서 씁니다.

## 3단계: 모션그래픽 + 내 목소리 더빙 영상 (`video.js`)

- 포스팅용 글 → 쇼츠·릴스 대본 / 롱폼 대본, 또는 목록의 "오늘 롱폼 대본"에서 **🎬 이 대본으로 더빙 영상 만들기**.
- 대본 한 줄 = 장면 하나. 장면을 보며 🎙로 한 줄씩 녹음하면 장면 길이가 녹음 길이에 맞춰져요.
- 모션 스타일은 책 주제로 자동 선택(펼쳐지는 페이지·잔잔한 물결·올라가는 선·궤도와 별·피어나는 원), 책마다 바꿀 수 있어요(`book.motion`).
- 녹음은 이 기기의 IndexedDB(`rn-dub`)에만 저장, GitHub에 올라가지 않아요.
- "영상 파일 만들기"는 실제 길이만큼 재생하며 녹화해요. 크롬·엣지에서 H.264를 지원하면 MP4, 아니면 WebM으로 저장돼요.
